# 静电实验室

解压后，用浏览器打开 `index.html` 即可预览。网页使用原生 HTML、CSS 和 JavaScript，无需安装依赖。

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面框架和脚本入口 |
| `content.js` | 章节、知识点、实验控件、填空题和答案 |
| `simulations.js` | Canvas 动画、实验模型和读数 |
| `app.js` | 章节导航、实验播放和重置、填空判分及浏览器本地保存 |
| `style.css` | 页面样式与横竖屏布局 |

新增实验时，在 `content.js` 对应章节的 `topics` 里添加一项，并在 `simulations.js` 的 `simulations` 里添加同名 ID 的绘制函数。函数接收画布上下文、与控件等序的数值数组和 0 到 1 的播放进度，并返回一行读数。章节列表、填空和实验链接从这份数据自动生成。

课程内容根据《ch9-10讲义》所列静电场考点整理。练习数据保存在填写时使用的浏览器中。
